<h1>ExamShield: Secure Online Examination Platform</h1>

<h2>Overview</h2>
<p>
ExamShield is a web-based platform designed to conduct online examinations with monitoring mechanisms that help reduce cheating and maintain exam integrity.
</p>

<p>
The system allows administrators, examiners, and students to interact with the platform through role-based access while ensuring fairness and security during online examinations.
</p>

<h2>Key Features</h2>
<ul>
<li>Secure login system with role-based access (Admin, Examiner, Student)</li>
<li>Timed examinations with automatic submission after time expiration</li>
<li>Randomized question order to reduce malpractice</li>
<li>Responsive real-time exam interface</li>
<li>Frontend tab-switch detection to identify suspicious behavior</li>
<li>Automatic result calculation and score display</li>
<li>User-friendly exam interface for smooth exam experience</li>
</ul>

<h2>Technology Enhancements</h2>
<ul>
<li>Client-side monitoring logic implemented for tab-switch detection</li>
<li>Modular and scalable frontend architecture</li>

</ul>
